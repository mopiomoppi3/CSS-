Animations

CSSアニメーション ギャラリー 6 パターン ・ ローディング

スピナー

境界線の一部だけ色を変えて回転させるシンプルなローダー。

コード
.spinner{
  border:3px solid #e3e3e6;
  border-top-color:#111;
  animation:spin .8s linear infinite;
}
@keyframes spin{to{transform:rotate(360deg)}}

ドット

3つの点が時間差でバウンドし、順番に弾む印象を作る。

コード
.dot{animation:bounce 1.4s ease-in-out infinite}
.dot:nth-child(2){animation-delay:.15s}
.dot:nth-child(3){animation-delay:.3s}
@keyframes bounce{
  0%,80%,100%{transform:translateY(0);opacity:.3}
  40%{transform:translateY(-10px);opacity:1}
}

パルス

円が中心から広がりながら透明になっていく、ソナーのような動き。

コード
.pulse::before,.pulse::after{
  animation:sonar 2s ease-out infinite;
}
.pulse::after{animation-delay:1s}
@keyframes sonar{
  0%{transform:scale(1);opacity:.55}
  100%{transform:scale(3.4);opacity:0}
}

イコライザー

5本のバーの高さが時間差で伸縮し、音の波のように見える。

コード
.bar{animation:scale 1.1s ease-in-out infinite}
.bar:nth-child(2){animation-delay:.12s}
/* ...以降も delay を .12s ずつずらす */
@keyframes scale{
  0%,100%{height:8px}
  50%{height:38px}
}

プログレス

ゴールの見えないタスク向け。バーが左右に走り続ける。

コード
.bar{
  position:absolute;left:-40%;width:40%;
  animation:slide 1.4s ease-in-out infinite;
}
@keyframes slide{
  0%{left:-40%} 100%{left:100%}
}

リップル

枠線だけの円が時間差で拡大し、水面の波紋のように消える。

コード
.ring{
  border:2px solid #111;
  animation:ripple 1.8s ease-out infinite;
}
@keyframes ripple{
  0%{transform:scale(.3);opacity:1}
  100%{transform:scale(1.7);opacity:0}
}

リフト

カーソルを乗せると影が広がりながら浮き上がる。（カードにホバー）

コード
.el{transition:transform .4s, box-shadow .4s}
.el:hover{
  transform:translateY(-10px);
  box-shadow:0 18px 26px rgba(0,0,0,.18);
}

アンダーライン

下線が左端から右端へ伸びていく定番のリンク表現。

コード
.link::after{
  content:'';width:0%;height:2px;
  background:#111;
  transition:width .45s;
}
.link:hover::after{width:100%}

アイコン回転

ホバーでアイコンが180度回転し、状態の切り替えを示す。

コード
.icon{transition:transform .5s}
.el:hover .icon{transform:rotate(180deg)}

ボーダードロー

ホバーで枠線が輪郭をなぞるように描かれていく。

コード
rect{
  stroke-dasharray:280;
  stroke-dashoffset:280;
  transition:stroke-dashoffset .6s;
}
.el:hover rect{stroke-dashoffset:0}

グロー

ホバーで輪郭ににじむような淡い光が広がる。

コード
.el{transition:box-shadow .4s, transform .4s}
.el:hover{
  box-shadow:0 0 0 1px #111, 0 0 32px 8px rgba(0,0,0,.32);
  transform:scale(1.06);
}
ボタン

マグネット

拡大とわずかな回転が重なり、吸い寄せられるように反応する。

コード
.btn{transition:transform .35s}
.btn:hover{
  transform:scale(1.12) rotate(-3deg);
}
こんにちは

タイピング

幅をステップ状に広げ、カーソルを点滅させてタイプ入力を再現。

コード
.text{
  width:5em;overflow:hidden;white-space:nowrap;
  border-right:2px solid #111;
  animation:typing 3.2s steps(5,end) infinite,
            caret .8s step-end infinite;
}
@keyframes caret{50%{border-color:transparent}}
グラデーション

グラデーション

文字に載せた背景グラデーションを流し、光沢感を出す。

コード
.text{
  background:linear-gradient(90deg,#111,#bbb,#111);
  background-size:200% auto;
  -webkit-background-clip:text;
  color:transparent;
  animation:shift 2.8s linear infinite;
}
@keyframes shift{to{background-position:-200% center}}
ウェーブ

ウェーブ

1文字ずつ遅延させて上下させ、波のような連なりを作る。

コード
span{animation:wave 1.3s ease-in-out infinite}
span:nth-child(2){animation-delay:.1s}
/* 以降も .1s ずつずらす */
@keyframes wave{
  0%,60%,100%{transform:translateY(0)}
  30%{transform:translateY(-9px)}
}
フォーカス

ぼかしイン

ぼけた状態から輪郭が現れ、再びぼけて消えていく。

コード
.text{animation:blur 2.6s ease-in-out infinite}
@keyframes blur{
  0%{filter:blur(9px);opacity:0}
  30%,70%{filter:blur(0);opacity:1}
  100%{filter:blur(9px);opacity:0}
}
グリッチ

グリッチ

複製したレイヤーを上下でずらし、ノイズのように揺らす。

コード
.text::before,.text::after{
  content:attr(data-text);
  position:absolute;inset:0;
}
.text::before{clip-path:inset(0 0 55% 0);animation:a 2.4s infinite}
.text::after{clip-path:inset(55% 0 0 0);animation:b 2.4s infinite}
ステップ

フェードアップ

文字が下から順番に浮かび上がり、消えてまた繰り返す。

コード
span{opacity:0;animation:fadeUp 2s ease infinite}
span:nth-child(2){animation-delay:.1s}
@keyframes fadeUp{
  0%{opacity:0;transform:translateY(12px)}
  25%,65%{opacity:1;transform:translateY(0)}
  100%{opacity:0;transform:translateY(-8px)}
}

ブロブ

border-radiusの4隅の比率を変化させ続け、有機的な形にする。

コード
.blob{animation:morph 6s ease-in-out infinite}
@keyframes morph{
  0%,100%{border-radius:42% 58% 65% 35% / 45% 45% 55% 55%}
  50%{border-radius:35% 65% 55% 45% / 40% 60% 40% 60%}
}

フリップ

ホバーでカードが3D回転し、裏面が現れる。（カードにホバー）

コード
.inner{
  transform-style:preserve-3d;
  transition:transform .7s;

.face{backface-visibility:hidden}

シェイプ回転

回転しながらborder-radiusも変化し、四角と円を行き来する。

コード
.shape{animation:spin 4s ease-in-out infinite}
@keyframes spin{
  0%{border-radius:16px;transform:rotate(0)}
  50%{border-radius:50%;transform:rotate(180deg)}
  100%{border-radius:16px;transform:rotate(360deg)}
}

バウンス

着地で潰れ、頂点で伸びる緩急により重力感を演出する。

コード
.ball{
  transform-origin:bottom center;
  animation:bounce 1.15s ease-in-out infinite;
}
@keyframes bounce{
  0%{transform:translateY(0) scaleX(1.25) scaleY(.75)}
  30%,50%{transform:translateY(-38px) scaleX(.92) scaleY(1.08)}
  72%,100%{transform:translateY(0) scaleX(1.25) scaleY(.75)}
}

スライドイン

図形が時間差で下から現れ、上へ抜けて消えていく。

コード
span{animation:slide 1.6s ease infinite}
span:nth-child(2){animation-delay:.15s}
@keyframes slide{
  0%{transform:translateY(18px) scaleY(.3);opacity:0}
  50%{transform:translateY(0) scaleY(1);opacity:1}
  100%{transform:translateY(-18px) scaleY(.3);opacity:0}
}

ブリージング

拡大縮小と不透明度をゆっくり繰り返す、呼吸のような動き。

コード
.el{animation:breathe 3s ease-in-out infinite}
@keyframes breathe{
  0%,100%{transform:scale(.82);opacity:.55}
  50%{transform:scale(1.06);opacity:1}
}
